X50 Patch Switcher (diagnostic test)

1. Unzip the WHOLE folder anywhere (right-click the zip, "Extract all").
   Do not run anything from inside the zip.
2. Plug the KORG X50 into the computer by USB and turn it on.
3. Double-click "Diagnose X50.bat".
4. Wait until it finishes. It opens a folder on the Desktop.
5. Send that whole folder back (zip it or send the files as they are).

Windows SmartScreen may warn the first time you run it. Click "More info",
then "Run anyway".

Nothing is installed on your computer, and nothing is written to the X50.
The program only asks the X50 what it is and which sound is selected.

Portable mode (optional): to keep the settings and your sets on a USB stick,
create an empty file named "portable" (no extension) next to the exe. The
program then saves everything in its own folder instead of the user profile.

Quick guide: "Guia rapida.pdf" (Spanish, one page) is in the same folder as the exe.
